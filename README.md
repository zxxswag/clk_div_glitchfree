# clk_div_glitchfree

无毛刺、可无缝切换分频系数的时钟分频器（Verilog RTL 单模块）。

## 特性

- 分频系数 `div_sel[2:0]` = N-1，支持 ÷1 ~ ÷8
- **无毛刺**：采用「低电平锁存 + AND」的时钟门控（ICG）结构，输出 `clk_div` 不会出现窄脉冲/毛刺
- **无缝切换**：新分频系数只在计数器回绕（分频周期边界）时刻锁存生效，切换绝不发生在半周期中间
- 异步复位（低有效），内部做复位释放同步

## 端口

| 端口 | 方向 | 位宽 | 说明 |
|---|---|---|---|
| `clk` | input | 1 | 输入时钟 |
| `rst_n` | input | 1 | 异步复位，低有效 |
| `div_sel` | input | 3 | 分频系数 N-1：`3'b000` → ÷1 ... `3'b111` → ÷8 |
| `clk_div` | output | 1 | 分频输出时钟（不保证 50% 占空比） |

## 工作原理

1. **复位同步**：异步复位立即生效，释放时刻与 `clk` 同步，避免 recovery/removal 时序违例。
2. **div_sel 同步**：`div_sel` 按准静态配置处理，经 2 拍同步。
3. **周期边界切换**：计数器 `cnt` 在 `0~ratio` 间循环，仅在回绕时锁存新系数 —— 无缝切换的核心。
4. **时钟使能 + ICG**：寄存器输出的 `en` 只在 `clk` 低电平期间进入锁存器，`clk_div = clk & en_l` 上不可能出现毛刺。

## 综合映射

- FPGA：`always @(*)` 低电平锁存 + AND 是 BUFGCE（时钟使能）标准推断模板
- ASIC：将「锁存 + 与门」替换为库 ICG 单元（如 CKLNQ）
